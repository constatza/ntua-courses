
# Εισαγωγή στο [uv](https://docs.astral.sh/uv/)

## 🧠 Θεμελιώδης Έννοια: Η Αναγκαιότητα των Εικονικών Περιβαλλόντων

Πριν την έναρξη της διαδικασίας εγκατάστασης, κρίνεται απαραίτητη η κατανόηση της τεχνικής αναγκαιότητας για την απομόνωση των περιβαλλόντων εκτέλεσης.

**Το Πρόβλημα των Συγκρουόμενων Εξαρτήσεων (Dependency Hell):**

Σε ένα λειτουργικό σύστημα χωρίς εικονικά περιβάλλοντα, όλες οι βιβλιοθήκες της Python εγκαθίστανται σε έναν κοινόχρηστο, καθολικό φάκελο (Global Site-Packages). Αυτό δημιουργεί σοβαρά προβλήματα συμβατότητας όταν διαφορετικά projects απαιτούν διαφορετικές εκδόσεις της ίδιας βιβλιοθήκης.

* **Σενάριο Σύγκρουσης:** Το "Project Α" απαιτεί τη βιβλιοθήκη `numpy-1.0`
για λόγους συμβατότητας παλαιού κώδικα (legacy), ενώ το "Project Β" 
απαιτεί την `numpy-2.0` για χρήση νεότερων λειτουργιών.
* **Αποτέλεσμα:** Η καθολική εγκατάσταση της έκδοσης `2.0` θα προκαλέσει δυσλειτουργία στο Project Α, ενώ η εγκατάσταση της `1.0` δεν θα καλύπτει τις απαιτήσεις του Project Β.

**Η Λύση:**
Η δημιουργία ενός **Εικονικού Περιβάλλοντος (Virtual Environment)** για κάθε project διασφαλίζει την πλήρη απομόνωση των εξαρτήσεων. Κάθε project διαθέτει τον δικό του κατάλογο βιβλιοθηκών και διερμηνέα Python, λειτουργώντας ανεξάρτητα από τα υπόλοιπα projects και το βασικό σύστημα.

> **Bέλτιστη Πρακτική:** Να αποφεύγεται η καθολική εγκατάσταση βιβλιοθηκών ανάπτυξης στο σύστημα. Η χρήση του `uv` αυτοματοποιεί τη δημιουργία και διαχείριση αυτών των απομονωμένων περιβαλλόντων.

## 🚀 Βήμα 1: Εγκατάσταση του `uv`

Απαιτείται η εκτέλεση της κατάλληλης εντολής ανάλογα με το λειτουργικό σύστημα. Το `uv` αναλαμβάνει εξ ολοκλήρου τη διαχείριση των εκδόσεων της Python.

- **Windows (PowerShell):**

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

- **macOS / Linux:**

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

> *Σημείωση: Σε περίπτωση που εμφανιστεί μήνυμα σφάλματος "uv not found" μετά την εγκατάσταση, βεβαιωθείτε ότι έχετε κάνει επανεκκίνηση του τερματικού.*

> 🔗 **Documentation:** [Οδηγός Εγκατάστασης uv](https://docs.astral.sh/uv/getting-started/installation/)

## 📁 Βήμα 2: Αρχικοποίηση Project

Η διαδικασία ξεκινά με τη δημιουργία του φακέλου και την αρχικοποίηση του νέου project.

```bash
# 1. Αρχικοποίηση φακέλου του project. Επιλέγουμε το όνομα myproject 
uv init myproject
# 2. Μπαίνουμε στο φάκελο (cd: change directory)
cd myproject
```

Με την εντολή αυτή, δημιουργούνται αυτόματα τα αρχεία `main.py` και 
`pyproject.toml` (αρχείο διαμόρφωσης και διαχείρισης εξαρτήσεων).

> 🔗 **Documentation:** [Οδηγός Projects uv](https://docs.astral.sh/uv/guides/projects/)

## 🪄 Βήμα 3: Εκτέλεση Κώδικα και Αυτόματη Ρύθμιση Περιβάλλοντος

Ακολουθεί η εκτέλεση του προεπιλεγμένου σεναρίου (script). **Σημειώνεται ότι, εάν δεν εντοπιστεί εγκατεστημένη έκδοση της Python, το `uv` προβαίνει αυτόματα στη λήψη και εγκατάστασή της.**

```bash
uv run main.py
```

**Αναμενόμενη έξοδος:**

```text
Using CPython 3.12.3
Creating virtual environment at: .venv
Hello from myproject!
```

**Ανάλυση Διαδικασίας:**

1. Ανίχνευση απαίτησης για Python και λήψη αυτόνομης έκδοσης (isolated build).
2. Δημιουργία **Εικονικού Περιβάλλοντος** στον κατάλογο `.venv`.
3. Εκτέλεση του σεναρίου εντός του απομονωμένου περιβάλλοντος.

🔗 **Documentation:** [Διαχείριση Έκδοσης Python με uv](https://docs.astral.sh/uv/guides/install-python/)

## 🧪 Βήμα 5: Εκτέλεση Σεναρίου Μηχανικής Μάθησης

Αντικατάσταση των περιεχομένων του `main.py` με κώδικα εκπαίδευσης μοντέλου γραμμικής παλινδρόμησης.

1. Διαγραφή του υπάρχοντος κώδικα στο `main.py`.
2. Εισαγωγή του ακόλουθου κώδικα:

```python
import numpy as np
from numpy.typing import NDArray
from sklearn.linear_model import LinearRegression

def run_training_pipeline() -> None:
    """
    Εκτελεί μια απλή διαδικασία εκπαίδευσης μοντέλου Γραμμικής Παλινδρόμησης.
    """
    # 1. Δημιουργία δεδομένων εκπαίδευσης (Training Data)
    # X: Πίνακας χαρακτηριστικών (Features) διαστάσεων (n_samples, n_features)
    X: NDArray[np.float64] = np.array([[1], [2], [3], [4], [5]])
    # y: Διάνυσμα στόχων (Targets) όπου y = 2x
    y: NDArray[np.float64] = np.array([2, 4, 6, 8, 10])

    # 2. Αρχικοποίηση και προσαρμογή (fit) του μοντέλου
    model = LinearRegression()
    model.fit(X, y)

    # 3. Πρόβλεψη νέας τιμής
    input_val: NDArray[np.float64] = np.array([[6]])
    prediction: NDArray[np.float64] = model.predict(input_val)

    print("Η εκπαίδευση του μοντέλου ολοκληρώθηκε επιτυχώς.")
    print(f"Πρόβλεψη για είσοδο 6 (Αναμενόμενη τιμή: 12): {prediction[0]:.2f}")

if __name__ == "__main__":
    run_training_pipeline()
```

**Εκτέλεση:**

```bash
uv run main.py
```

## 🛠️ Βήμα 6: Παραμετροποίηση Περιβάλλοντος Ανάπτυξης (IDE)

> *Σημ: Πολλά IDEs μπορούν να δημιουργήσουν μέσα 
από το γραφικά μενού τους τα εικονικά περιβάλλοντα καθώς και να 
διαχειριστούν πακέτα python. Στην ουσία κάνουν ό τι περιγράφεται 
στα βήματα 1. έως 4. με κάποιον package manager (uv ή αλλον). 
Η χρήση τερματικού όμως είναι πάντα πιο γενική και πιο αξιόπιστη.*

Για τη σωστή λειτουργία του IDE (π.χ. VS Code, PyCharm), 
την ενεργοποίηση της αυτόματης συμπλήρωσης κώδικα και τον εντοπισμό σφαλμάτων, 
**απαιτείται η ρητή δήλωση του διερμηνευτή Python (interpreter) 
ο οποίος βρίσκεται εντός του εικονικού μας περιβάλλοντος.**

Η διαδρομή του εκτελέσιμου αρχείου είναι η εξής:

* **Windows:** `myproject\.venv\Scripts\python.exe`
* **macOS / Linux:** `myproject/.venv/bin/python`

### **Visual Studio Code (VS Code)**

1. Άνοιγμα του φακέλου του project (`myproject`) στο VS Code.
2. Άνοιγμα του αρχείου `main.py`.
3. Εκτέλεση της παλέτας εντολών με `Ctrl+Shift+P` (Windows) ή `Cmd+Shift+P` (Mac).
4. Επιλογή της εντολής: **Python: Select Interpreter**.
5. Επιλογή της διαδρομής: **"Enter interpreter path..."** -> **"Find..."**.
6. Πλοήγηση στον φάκελο `.venv` και επιλογή του κατάλληλου εκτελέσιμου αρχείου Python.

### **PyCharm**

1. Εκκίνηση του PyCharm, επιλογή **Open** και φόρτωση του φακέλου `myproject`.
2. Μετάβαση στις ρυθμίσεις (**Settings** ή **Preferences**).
3. Πλοήγηση στην ενότητα: **Project: myproject** > **Python Interpreter**.
4. Επιλογή **Add Interpreter** > **Local...** > **Virtualenv Environment**.
5. Επιλογή της ρύθμισης **Existing environment**.
6. Επιλογή του εκτελέσιμου αρχείου Python εντός του φακέλου `.venv` μέσω του περιηγητή αρχείων.

Όταν το IDE έχει πλέον την σωστή διεύθυνση του διερμηνευτή, μπορούμε εύκολα να 
εκτελούμε τα προγράμματα και με γραφικό τρόπο όπως έχουμε συνηθίσει.
