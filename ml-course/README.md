# Machine Learning — NTUA

Lecture decks for the machine learning course at NTUA School of Civil Engineering.
All decks use the `ntuabeamer` class and are built from LaTeX with optional Python
figures generated by [`uv`](https://docs.astral.sh/uv/).

Topic ownership is tracked in `TOPICS.toml`: each concept has one owning deck,
and other decks cross-reference it instead of re-explaining.

Books, slides, datasets and assignments are not in this repo.

## Slides

All lecture decks are published as PDFs on GitHub Releases:

[slides](https://github.com/constatza/machine-learning/releases)

Each deck is a single PDF. Download whichever you need — no clone required.

## Suggested reading order

1. Supervised learning — problem formulation and linear baselines
2. Neural nets — dense networks, backpropagation, approximation
3. Optimization — first-order algorithms through Adam
4. Regularization — generalization, bias–variance, penalties
5. Geometric deep learning — symmetry, invariance, equivariance
6. CNNs — convolutional architectures
7. RNNs — recurrent architectures
8. Transformers — attention-based sequence models
9. GNNs — message passing on graphs
10. PINNs & neural operators — scientific ML
11. Diffusion models
12. Flow matching
13. PCA / POD / ROM
14. PDF distances

## For instructors & developers (clone & build)

Requires TeX Live with `latexmk`, and [`uv`](https://docs.astral.sh/uv/) for the Python demos.

```sh
git clone <this-repo> && cd machine-learning
curl -fsSL https://raw.githubusercontent.com/constatza/beamer-ntua/main/scripts/install-class.sh | sh   # once; writes to TEXMFHOME
tools/build-all                  # or: cd presentations/<deck> && latexmk -pdf main.tex
```

Install the `ntuabeamer` class before building. The install script respects
`NTUA_BEAMER_REF`; this course is pinned to `v0.1.0-alpha.1`:

```sh
NTUA_BEAMER_REF=v0.1.0-alpha.1 curl -fsSL https://raw.githubusercontent.com/constatza/beamer-ntua/main/scripts/install-class.sh | sh
```

Each deck builds into its own `.build/`. Built PDFs are not committed to git.
